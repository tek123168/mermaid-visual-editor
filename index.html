Why Mermaid Canvas

Mermaid is everywhere — GitHub, GitLab, Notion, Obsidian — but it is text-first and unforgiving. General diagram tools don't round-trip with Mermaid code. Mermaid Canvas closes that gap.

⌨️

Text-first and unforgiving

Mermaid syntax errors break your render, and there is no way to fix them by looking at the picture. Canvas surfaces errors with line numbers instantly — and lets you fix them by clicking the diagram.

📐

Layout is auto-computed

You can't nudge a node without hacking coordinates or loop strategies. Canvas keeps Mermaid's auto-layout (so it still renders in GitHub) but edits labels and styles by point-and-click.

🔁

Tools don't round-trip

Draw.io, Excalidraw and Miro don't speak Mermaid. Paste code, tweak it visually, export PNG/SVG and commit the same Mermaid source back to the repo — no dead-ends.

How it works

Import

Paste Mermaid code or drop in a .mmd / .md file. Start from a demo and modify it.

Click to edit

Click any node or edge. Change labels, fill colors, strokes and text colors — the source updates in real time, both ways.

Export

Download clean PNG (free) or SVG/PDF (Pro) for READMEs, docs, Notion and slide decks.

Commit

Copy the Mermaid code back into your repo. The diagram lives in the codebase, exactly like your team wanted.
